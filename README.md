# Бот для аренды вертолетов (aiogram 3 + FastAPI Webhooks)

Этот бот предназначен для анкетирования пользователей, желающих арендовать вертолет в Уфе.

## Функционал
1. Анкетирование (Цель, дата, кол-во человек, маршрут, бюджет, доп. услуги, телефон).
2. Пересылка результатов администраторам.
3. Отправка информационного сообщения пользователю в зависимости от выбранной цели.

## Установка

1. Склонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example` и заполните его:
   - `BOT_TOKEN`: Токен вашего бота от @BotFather.
   - `ADMIN_IDS`: ID администраторов через запятую (например, 12345678,87654321).
   - `WEBHOOK_URL`: Публичный URL вашего сервера (например, https://your-domain.com).
   - `WEB_SERVER_HOST`: Хост для запуска сервера (по умолчанию 0.0.0.0).
   - `WEB_SERVER_PORT`: Порт для запуска сервера (по умолчанию 8080).

## Запуск

```bash
python main.py
```

## Использование с Ngrok (для локальной разработки)

1. Запустите ngrok:
   ```bash
   ngrok http 8080
   ```
2. Скопируйте полученный https URL в `WEBHOOK_URL` в файле `.env`.
3. Запустите бота: `python main.py`.
