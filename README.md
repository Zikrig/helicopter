# Бот для аренды вертолетов (aiogram 3 + Docker)

Этот бот предназначен для анкетирования пользователей, желающих арендовать вертолет в Уфе.

## Функционал
1. Анкетирование (Цель, дата, кол-во человек, маршрут, бюджет, доп. услуги, телефон).
2. Пересылка результатов администраторам.
3. Отправка информационного сообщения пользователю в зависимости от выбранной цели.

## Установка и запуск (Docker)

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_вашего_репозитория>
   cd helicopter
   ```

2. **Создайте файл `.env`** и заполните его:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_IDS=12345678,87654321
   ```

3. **Запустите бота**:
   ```bash
   docker compose up -d --build
   ```

## Запуск без Docker

1. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите бота**:
   ```bash
   python main.py
   ```

## Как это работает
Бот работает в режиме **Polling** (опрос серверов Telegram). Это самый простой способ запуска, который не требует наличия домена, SSL-сертификатов или настройки веб-сервера (Nginx). Бот сам подключается к Telegram и забирает новые сообщения.
